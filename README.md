# TSRealDriver.dll

Independent ETS2/ATS driver-walking plug-in built from scratch.

## Version 0.3

The current build contains runtime walking controls, interaction overlays, an original configuration panel, synthesized local sounds, and the first TSRealDriver fuel-roleplay flow.

### Implemented

- `F10` toggles walk mode using the game's developer/free camera.
- Automatic initial offset away from the driver's seat.
- `W A S D` movement bridge.
- `Shift` run-speed boost.
- `Ctrl` crouch / eye lowering.
- `Space` jump cycle.
- `Q / E` manual eye-height movement and `R` reset pulse.
- `F` interaction / return to cab when not in another interaction flow.
- `F8` building/ghost-walk mode state.
- `~` pauses TSRealDriver walking input while using the console.
- Right mouse button flashlight overlay and `G` beam-size cycle.
- Screen-space driver-shadow fallback while walking.
- Fade-to-black enter/exit transition.
- Footstep timing based on walking/running speed and configured stride.
- Head-bob / sway camera nudge while stepping.
- Tired breathing after sustained running.
- Original local sounds generated by TSRealDriver at runtime for footsteps, door, flashlight, card, nozzle, receipt and breathing.
- `Ctrl+F10` opens the TSRealDriver settings panel.
- Dark tabbed settings UI with:
  - Movement
  - Walk Style
  - Camera
  - Flashlight
  - Sound
  - Shadow
  - Fuel
  - Keys
- Sliders, switches, presets and editable hotkeys.
- `TSRealDriver.ini` hot reload after saving.
- On-screen TS REAL DRIVER status/prompt overlay.
- Fuel-roleplay state flow:
  1. TS Fleet card
  2. nozzle
  3. hold `F` to hold the game's Enter key while filling
  4. receipt
- Local `TSRealDriver.log`.

## Game requirement

The current walking engine uses the developer/free camera included in ETS2/ATS. Enable in the game's `config.cfg`:

```
uset g_developer "1"
```

## Install

Copy the Windows x64 package contents to:

```
<game>\bin\win_x64\plugins\
```

The package contains:

```
TSRealDriver.dll
TSRealDriver.ini
TSRealDriverConfig.exe
README.md
```

## Important current limitation

Version 0.3 is feature-rich but is still a beta, not the final 1.0. The remaining hard integration work is world-space data that the developer/free-camera bridge alone cannot provide reliably: true terrain collision, exact truck-door proximity, real 3D light projection, world-space hand models, and automatic pump/tank geometry detection across truck models.

Those pieces need a deeper game-integration layer and real ETS2/ATS testing rather than fake configuration switches.

## Clean-room boundary

TSRealDriver contains its own code, branding, runtime-generated sounds and TS Fleet visuals. It does not contain another plug-in's source code, licence/token system, private server endpoints, copied images, copied sounds, or copied menu artwork.
